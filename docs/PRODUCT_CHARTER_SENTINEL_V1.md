# Koschei Sentinel — standalone cybersecurity AI charter v1

Koschei Sentinel is an independent commercial cybersecurity AI product. It is sold separately from Koschei Web3 Hub and Koschei Lang.

## Product mission

Build a world-class cybersecurity intelligence AI focused on defensive security engineering, vulnerability discovery, secure code reasoning, threat analysis, incident understanding and evidence-grounded remediation support.

"World-class" is a product target, not an unevidenced benchmark claim. Readiness and superiority claims require executed evaluations, reproducible evidence and independent release gates.

## Core product scope

Sentinel should develop independent capability for defensive use cases including:

- source-code and architecture security review;
- vulnerability reasoning and secure remediation guidance;
- attack-path and exposure analysis;
- dependency, configuration and secret-risk reasoning;
- defensive threat modeling;
- incident evidence interpretation and triage support;
- cloud, application, API, identity and infrastructure security reasoning;
- smart-contract and blockchain security reasoning as one cybersecurity domain, not as Sentinel's product identity;
- phishing, fraud and malicious-behavior analysis where evidence is available;
- security control review, policy reasoning and defensive engineering recommendations;
- evidence-grounded security explanations with explicit limitations and confidence.

## Independent authority

Sentinel owns its own model architecture, training/evaluation pipeline, datasets, promotion gates, inference services and cybersecurity product roadmap.

It must not be reduced to an ARVIS feature, Web3 plugin or Lang compiler component.

## Interoperability

Sentinel may consume cases from Koschei Web3 Hub, Koschei Lang or other systems through explicit versioned contracts. Such integrations are optional product-to-product interoperability.

Interoperability does not create shared billing, shared entitlement or automatic authority. Each product keeps its own release and safety gates.

## Commercial rule

Sentinel has its own pricing, entitlement, billing and customer-access policy. Buying Web3 or Lang does not automatically grant Sentinel access, and buying Sentinel does not automatically grant the other products.
