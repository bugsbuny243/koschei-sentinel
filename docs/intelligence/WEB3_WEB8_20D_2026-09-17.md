# Web3–Web8 20-Day Intelligence — Koschei Sentinel

Window: 2026-08-29 → 2026-09-21

Sentinel is treated here as a cybersecurity foundation model, not a scanner.

## Existing capability directions
- Trust-chain reasoning across identity, credential, code, observation source, protocol rule, authorization, state transition, effect and evidence.
- Multi-hop agent authorization and execution/action finality.
- PQ migration, cross-chain causality, artifact identity, standards lifecycle and agent accountability causal provenance.

## 2026-09-21 fresh intake

### Intent identity, resolution and execution target must remain distinct
`draft-li-rttp-intent-addressing-01` (2026-09-20) defines an `rttp` URI for claims of intent directed at identified subjects, with computational address derivation and explicit handling requirements against open-redirect and protocol-handler launcher failure modes. It is an Independent Submission Informational Internet-Draft, not an RFC.

**Opportunity:** add `INTENT_RESOLUTION_CONTINUITY` reasoning: prove that declared intent, identified subject, derived/resolved target, current authority and eventual effect still refer to the same security-relevant action.

**Threat:** a valid intent identifier can still be resolved or handled unsafely; identity/intent integrity does not prove execution-target safety.

**Competitor gap:** combine URI/resolution security with agent authority, provenance and effect reasoning rather than treating it as a browser-only redirect problem.

**Benchmark idea:** adversarial cases where `intent -> subject -> resolution -> execution target -> effect` diverges while each local component appears syntactically/cryptographically valid.

### AIIP/AIID proposes a separate consequential-action plane
`draft-sogomonian-aiip-aiid-00` (2026-09-20) combines durable principal identity, an agent-only access plane, signed execution receipts, monitoring/freeze and revocation. It is an Experimental Internet-Draft, not an adopted IETF standard.

**Opportunity:** add `CONTROL_PLANE_EFFECT_CONTINUITY`: reason whether identity/access-plane state, revocation/freeze state, candidate action and signed receipt correspond to the actual effect.

**Threat:** a protocol can provide strong identity/receipts while application semantics, authority scope or external state remain wrong.

**Competitor gap:** Sentinel can reason across `identity -> access plane -> grant -> revocation/freeze -> invoke -> effect -> receipt`, independent of which agent protocol wins.

### Standards lifecycle
AGTP revision 01 reaches its stated 2026-09-21 expiry. Treat this as lifecycle evidence, not as a newly deployed protocol. Protocol concepts should be learned separately from transient draft names.

## Standards reality
No accepted IETF/W3C Web4/Web5/Web6/Web7/Web8 generation standard was identified. RTTP and AIIP/AIID are Internet-Drafts; AGTP expiry is a lifecycle event. The durable security primitives are intent, identity, authority, resolution, revocation, effect and evidence.
