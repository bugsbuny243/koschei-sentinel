# Web3–Web8 Intelligence — Koschei Sentinel

Window: 2026-08-29 → 2026-09-22

Sentinel is treated as a cybersecurity foundation model, not a scanner.

## Existing capability directions
Trust-chain reasoning; multi-hop authorization; action finality; PQ migration; cross-chain causality; artifact identity; standards lifecycle; accountability; intent-resolution continuity; control-plane/effect continuity.

## 2026-09-22 fresh intake

### Runtime agent security is converging on causal graphs
Salt Security announced native AI Detection and Response on 2026-09-22, explicitly correlating LLM-layer attacks such as prompt injection with downstream MCP servers, tools and APIs in an Agentic Security Graph.

**Opportunity:** this validates Sentinel's causal-graph direction, but also exposes direct competition.

**Threat:** competitors are moving from isolated prompt filtering to model -> tool -> API attack-chain correlation.

**Competitor gap:** Sentinel should go deeper than telemetry correlation by reasoning about authority, policy freshness, state validity, provenance and whether the downstream effect was actually authorized.

**Benchmark/product idea:** `MODEL_TO_EFFECT_CAUSALITY`: reconstruct `input/context -> model decision -> tool/MCP selection -> credential/authority -> API/chain call -> state transition -> effect -> evidence`, including adversarial cases where telemetry is locally valid but authority/state semantics are wrong.

### Agent identity controls are moving into runtime enforcement
Okta's 2026-09-22 announcements emphasize agent identities as first-class non-human identities, runtime enforcement and kill-switch controls; Aembit announced XAA support. XAA is an open vendor protocol/ecosystem, not an IETF/W3C standard.

**Opportunity:** add `RUNTIME_AUTHORITY_REVOCATION` reasoning across identity lifecycle, token/capability state, policy change, revocation and already-running agent actions.

**Threat:** a valid login-time identity or delegated connection can outlive the policy that originally allowed it.

**Competitor gap:** reason about revocation racing with in-flight actions and irreversible effects, rather than only enforcing access at request boundaries.

### PQ security is being coupled with blast-radius control
Aviatrix announced Harvest and Decrypt Protection on 2026-09-22, combining crypto-agile/post-quantum protection with workload communication governance and reachability containment.

**Opportunity:** strengthen `PQ_MIGRATION` into `PQ_PLUS_CONTAINMENT`: cryptographic confidentiality and compromise blast radius are independent dimensions.

**Threat:** organizations may treat PQ encryption as sufficient while compromised workloads retain excessive reachability.

**Benchmark idea:** cases where cryptography is strong but topology/authorization still enables harmful propagation or data access.

### MCP becomes a security-context integration surface
Wiz announced MCP-powered WIN integrations that let partner agents retrieve live security findings/context.

**Opportunity:** train Sentinel to consume external security context without confusing context with authority or truth.

**Threat:** stale/poisoned/over-broad context can steer agent decisions downstream.

## Standards reality
No accepted IETF/W3C Web4/Web5/Web6/Web7/Web8 generation standard was identified in the last 24 hours. XAA is an open vendor protocol/ecosystem; MCP is an open application protocol with broad adoption; today's Salt/Okta/Wiz/Aviatrix changes are product/security architecture developments, not new Internet-generation standards.
